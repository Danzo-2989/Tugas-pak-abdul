## 📖 Tentang Project
Repositori ini berisi kumpulan tugas web dari Pak Abdul. Proyek ini dibangun sepenuhnya menggunakan **HTML** dan **CSS** murni untuk menciptakan antarmuka (UI) yang rapi, dengan beberapa fitur seperti simulasi login, pemesanan, dan pembayaran.

## 📂 Struktur Halaman & File
Proyek ini terdiri dari beberapa halaman yang saling terhubung:
- 🏠 `index.html` — Halaman utama / Beranda
- 🔐 `login.html` — Halaman masuk pengguna
- 📝 `register.html` — Halaman pendaftaran
- 🛒 `pesan.html` — Halaman pemesanan layanan/barang
- 💳 `bayar.html` — Halaman proses pembayaran
- 🧾 `struk.html` — Halaman bukti transaksi
- 📊 `status.html` — Halaman untuk melihat status pesanan
- 🎨 `style.css` — File styling (desain UI) utama
- ⚙️ `dawn-standalone.jar` — File *executable* (opsional untuk *helper/backend*)

## 🚀 Cara Menjalankan (Local)

1. Clone repositori ini ke komputer kamu:
   ```bash
   git clone https://github.com/Danzo-2989/Tugas-pak-abdul.git
   ```
2. Buka folder proyek:
   ```bash
   cd Tugas-pak-abdul
   ```
3. Klik dua kali atau jalankan file `index.html` menggunakan browser favoritmu (Google Chrome, Mozilla Firefox, dll).
